# news-image-20261122

A 1024x1024 news mosaic summing up the world's news of Sunday 22 November 2026:
3 hero stories, an 8-card grid, a 12-pin dotted world map with a continent
legend, a 24-item "Also on Sunday" brief list, and a day-in-numbers band.
35 stories across 6 continents. Generated deterministically by
an HTML/CSS poster rendered headless, then cropped to 1024x1024.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

The program copies `entry.png` to the output directory. Built for the
[make.fun](https://make.fun/bounty/news-image-20261122) competition
news-image-20261122.
